# Avatars

Default avatars shipped with Rustle3D. Every file here must have a license
that allows commercial redistribution, and an entry below.

Planned (milestone M5): one female and one male avatar derived from the
MakeHuman base mesh (CC0 1.0), decimated to a few MB, in glTF binary (`.glb`),
metres, Y-up, standing A-pose, with named arrangement landmarks.
